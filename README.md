# SigmaOS adaptability

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-adaptability`.

No adaptive behavior or multimedia, office, or networking implementation is present in the current source.

## Build

```sh
cargo check --lib
```
